## Findings

Endpoints that refuse a non-browser `User-Agent`:
- **股吧个股列表 (HTML)** — FAIL (HTTP 403) with Python's agent, ok with a browser agent.

This is a user-agent filter, not a JavaScript wall: `curl/8.5.0` passes it. The platform sends a browser agent on every request, so the filter has no practical effect here.

Everything else — push2 quotes, klines, trends, fund flow, ticks, the limit-up/limit-down pools, datacenter reports (dragon-tiger, margin), announcements, research, the 7x24 feed, news columns and all article pages — answers plain Python, sets no required cookies, and needs no browser or JS runtime.

### Notes

- `datacenter-web` returns one `Set-Cookie` header but serves the JSON correctly when it is ignored.
- `emappdata` (popularity ranking) is the only endpoint requiring `POST`.
- `newsapi` replies with JSONP (`var ajaxResult={...}`); strip the prefix before parsing.
- `gbapi.eastmoney.com/webarticlelist` always returns HTTP 200 with an empty `re` array for unauthenticated clients; it is not usable for market-wide community data, which is why the community feed reads the server-rendered list pages instead.
- `robots.txt`: `www.eastmoney.com` publishes `User-agent: * / Allow: /`; `quote`, `guba` and `datacenter` host none (404).
